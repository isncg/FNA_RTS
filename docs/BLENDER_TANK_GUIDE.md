# 坦克模型制作与导出规范

> **面向对象**：Blender 美术建模人员
> **配套脚本**：[tools/export_tank.py](../tools/export_tank.py)
> **阅读时间**：约 10 分钟

本文档说明坦克模型需要如何**拆分部件、命名、设置枢轴点**，以及如何使用导出脚本生成游戏所需的 GLB 文件。请在建模前通读，导出前逐项核对第 8 节检查清单。

---

## 1. 游戏需要什么

游戏中的坦克是 3D 模型，由多个**独立网格部件**组成。游戏运行时会对不同部件施加**不同的旋转**：

| 部件 | 游戏内动态 |
|------|-----------|
| 车体（Hull） | 绕坦克中心水平旋转（车身转向） |
| 炮塔（Turret） | 绕炮塔座圈水平旋转（炮塔指向，可独立于车身转动） |
| 负重轮（Wheel*） | 绕轮轴旋转（未来细节：行进时轮子转动） |
| 履带（Track*） | 静态（未来细节：履带滚动动画） |

因此**部件必须分开建模，不能把所有几何合并成一个网格**。游戏通过**对象名称前缀**识别每个部件的角色——前缀错了，部件就不会动，或者会被当静态细节处理。

### 1.1 命名约定（必须遵守）

| 名称前缀 | 角色 | 游戏内行为 | 是否必需 |
|---------|------|-----------|---------|
| `Hull` | 车体 | 随车身转向旋转 | **必需** |
| `Turret` | 炮塔（可含炮管） | 绕座圈旋转 | **必需** |
| `Barrel` | 独立炮管（可选） | 跟随炮塔 | 可选 |
| `TrackL` / `TrackR` | 左右履带 | 静态（未来 UV 滚动） | 可选 |
| `WheelL_01`、`WheelR_02` … | 负重轮 | 绕轮轴旋转 | 可选 |
| 其他任何名字 | 静态细节 | 游戏加载时并入车体 | 可选 |

名称不区分大小写，但**前缀必须正确**。示例：`Hull`、`hull_body`、`HULL_Main` 都可以，但 `Body`、`Tank_Body`、`Turet`（拼写错误）不会被识别。

### 1.2 推荐的层级结构

```
TankRoot（空对象，可选，仅用于组织）
├── Hull            ← 车体（必需）
├── TrackL          ← 左履带
├── TrackR          ← 右履带
├── WheelL_01       ← 左侧负重轮（编号从车头开始）
├── WheelL_02
├── WheelL_03
├── WheelR_01
├── WheelR_02
├── WheelR_03
└── Turret          ← 炮塔（必需）
    └── Barrel      ← 独立炮管（可选，作为 Turret 的子对象）
```

**炮管可以二选一**：
- 与炮塔合并为同一个网格（原点仍必须设在座圈中心）——当前版本推荐，面数更省；
- 作为 `Turret` 的子对象独立建模——为未来火炮俯仰/后座动画保留可能性。

两种方式游戏都支持，**建模时请保留独立对象**（将来拆分方便），交付时是否合并都行。

### 1.3 MBT 真实布局（本游戏的设计基准）

游戏当前的坦克遵循真实主战坦克（MBT）布局，导出校验也以此为依据：

- **炮塔座圈位于车体中心前方**（引擎舱占据车体后部）
- **炮塔尾舱（bustle）向后延伸**，平衡炮管重量——炮塔几何以座圈为界，前短后长
- 车体后部有**发动机舱盖板**（可并入车体网格，或单独命名如 `EngineDeck` 作为静态细节）

建议模型遵循此布局，炮塔座圈不要设在车体正中心。

## 2. 坐标系与单位

- 使用 Blender 默认坐标系：**Z 轴向上**
- **车头朝向 +Y**（绿色轴方向），炮管初始指向 +Y
- 模型的**世界原点（0, 0, 0）位于车体中心在地面上的投影**——即车体底部中心落在地面

```
        Z（蓝，上）
        ↑
        │       车头 → +Y（绿）
        │      ╱
        │    ╱
        │  ╱
        ────────→ X（红，右）
```

- 导出为 glTF 标准格式（Y 轴向上），坐标换算由游戏端处理，**建模时无需关心**

### 单位比例

**1 Blender 单位 = 1 游戏单位**。参考当前游戏内坦克尺寸（按第 1.3 节 MBT 布局）：

| 部位 | 参考尺寸 |
|------|---------|
| 车体（长×宽×高） | 24 × 16 × 8 |
| 总长（含炮管） | ≈ 38 |
| 总高 | ≈ 15 |
| 炮塔座圈高度 | ≈ 6（地面上方） |
| 座圈相对车体中心 | 前移 ≈ 4 |
| 炮塔（座圈前/后延伸） | 前 6 / 后 9 |
| 负重轮直径 | ≈ 4~5 |
| 一格地图瓦片 | 64 单位宽（坦克约占 0.6 格） |

不必精确匹配上述数值，但**所有部件必须使用同一比例**，并且不要使用缩放导入/导出的模型（如单位 0.01 的工业资产），否则会破坏碰撞与寻路尺寸。

## 3. 枢轴点（最重要的要求）

**每个网格对象的原点（Origin）必须位于它的旋转枢轴点**。游戏对部件做旋转时，绕的就是对象原点。枢轴点错误 = 炮塔绕着错误的位置转。

| 部件 | 原点位置 |
|------|---------|
| `Hull` | 车体中心在地面的投影 (0, 0, 0) |
| `Turret` | **炮塔座圈中心**（炮塔与车体的连接点） |
| `Barrel` | 炮管根部（与炮塔的连接点） |
| `Wheel*` | **轮轴中心**（轮子圆心） |
| `Track*` | 任意（静态部件） |

### 设置方法（以炮塔为例）

1. 进入**编辑模式**，选中座圈中心附近的顶点或面
2. `Shift + S` → **游标到选中项**（Cursor to Selected）
3. 回到**对象模式**，选中炮塔对象
4. 右键 → **设置原点**（Set Origin）→ **原点到 3D 游标**（Origin to 3D Cursor）

> 注意：移动对象（`G`）不会改变原点位置，原点跟着对象走；设置原点后如果部件位置不对，直接移动对象即可。

### 检查原点的小技巧

选中对象，看 Blender 视口里的**橙色原点点**：
- 炮塔 → 原点应显示在座圈中心，而不是炮塔几何中心
- 车轮 → 原点应在轮心，而不是车轮边缘

## 4. 材质与颜色

> 游戏目前没有正式的美术风格和渲染管线设计，本节只列出**技术性约束**，不限制风格表达。

- **每个网格必须至少有一个材质或顶点色**，否则游戏里会渲染为黑色（导出脚本会检查并警告）
- 材质建议通过 Principled BSDF 的 Base Color 设置颜色；游戏渲染管线尚未定型，后续可能读取基础色、顶点色或贴图，请确保三者之一始终可辨认
- **纹理贴图**：GLB 会包含贴图，但游戏当前渲染管线尚未启用贴图采样。如果使用贴图，请同时保证基础色可辨认，避免无贴图时模型全黑
- **履带 UV 建议**：如果履带使用贴图，将 UV 的 **U 方向对齐履带行进方向**（即 +Y），为未来的履带滚动动画做准备

## 5. 会被自动清除的内容

导出脚本会自动删除/剥离以下内容，**无需手动清理**（手动清理可以减小源文件体积）：

| 内容 | 处理方式 |
|------|---------|
| 灯光（Light） | 自动删除 |
| 相机（Camera） | 自动删除 |
| 动作/动画（Action / Animation） | 自动删除（游戏动画由逻辑驱动，不需要动画数据） |
| 骨骼/绑定（Armature） | 自动删除（游戏不支持骨骼动画） |
| 形变键（Shape Keys） | 导出时忽略 |
| 曲线/晶格/扬声器/材质预览世界等 | 自动删除 |

**会被保留并导出**：网格、空对象、材质、贴图、UV、顶点色、修改器。

- **修改器**：导出时自动应用（结果烘焙进网格）。但建议建模收尾时手动 `Ctrl+A` 应用常用修改器，避免意外
- **对象旋转与缩放**：会被导出并由游戏正确解析，但强烈建议所有网格对象保持**旋转 = 0、缩放 = 1**（收尾时 `Ctrl+A` → All Transforms）。非标准变换会给后续维护和排查带来麻烦

## 6. 面数预算

| 部件 | 三角面数上限 |
|------|------------|
| 车体 | 2,000 |
| 炮塔（含炮管） | 1,500 |
| 单条履带 | 800 |
| 单个负重轮 | 300 |
| **全车合计** | **5,000（目标 3,000）** |

导出脚本会报告每个部件的面数并警告超预算。当前无需制作 LOD。

## 7. 导出

### 7.1 单模型导出

```bash
blender --background --python tools/export_tank.py -- \
    --model models/tank.blend \
    --output data/models/tank.glb
```

### 7.2 只校验不导出（推荐导出前先跑一遍）

```bash
blender --background --python tools/export_tank.py -- \
    --model models/tank.blend --check-only
```

### 7.3 批量导出（JSON manifest）

创建 `tools/tanks_manifest.json`：

```json
[
  { "id": "tank",       "model": "models/tank.blend",       "output": "data/models/tank.glb" },
  { "id": "tank_heavy", "model": "models/tank_heavy.blend", "output": "data/models/tank_heavy.glb" }
]
```

```bash
blender --background --python tools/export_tank.py -- \
    --from-json tools/tanks_manifest.json --batch
```

### 7.4 严格模式

校验警告（如枢轴点可疑）在默认情况下不阻止导出；加 `--strict` 后任何警告都会导致导出失败：

```bash
blender --background --python tools/export_tank.py -- \
    --model models/tank.blend --strict
```

### 7.5 Blender 内交互使用

打开 Blender → Scripting 工作区：

```python
import export_tank
export_tank.export_tank(blend_path="models/tank.blend", output_path="data/models/tank.glb")
```

> 注意：脚本会打开指定的 .blend 并替换当前场景，请先保存工作。

### 7.6 导出报告解读

脚本会输出校验报告，例如：

```
── Model Report ───────────────────────────────
  Hull             Hull (body) — required          1,842 tris  2 mat(s)
  Turret           Turret — required                 927 tris  1 mat(s)
  WheelL_01        Wheel (spins around local X)       96 tris  1 mat(s)
  ...
  TOTAL                                            3,200 tris

── Validation ─────────────────────────────────
  ✓  All checks passed
```

或发现问题时：

```
── Validation ─────────────────────────────────
  ✗ WARN:  'Turret': origin at ground level — pivot likely missing (must be at the turret ring)
  ✗ WARN:  'Turret': object is rotated — apply transforms with Ctrl+A
```

`✓` = 通过；`✗` = 警告（默认不阻止导出）或错误（始终阻止导出）。**建议报告完全干净后再交付**。

## 8. 导出前检查清单

- [ ] 车体和炮塔是**独立网格**，命名以 `Hull` / `Turret` 开头
- [ ] 炮塔原点在**座圈中心**（橙色原点显示在座圈处）
- [ ] 车体原点在**地面中心** (0, 0, 0)
- [ ] 负重轮独立网格，命名以 `Wheel` 开头，原点在轮轴中心
- [ ] 车头朝向 **+Y**，炮管初始指向 +Y
- [ ] 座圈位于车体中心**前方**，炮塔尾舱向后延伸（MBT 布局）
- [ ] 所有网格对象旋转 = 0、缩放 = 1（`Ctrl+A` 应用过变换）
- [ ] 每个网格有材质或顶点色（不会全黑）
- [ ] 全车 ≤ 5,000 三角面
- [ ] 灯光/相机/动画已删除（脚本会自动删，删除可减小体积）
- [ ] 先跑 `--check-only`，报告无 `✗` 后正式导出

## 9. 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 游戏里炮塔绕车体中心转 | 炮塔原点不在座圈 | 重新设置原点（见第 3 节） |
| 车身转向时整体偏移 | 车体原点不在车体中心 | 原点设回车体中心地面 |
| 模型显示为黑色 | 网格没有材质也没有顶点色 | 添加材质并设置 Base Color |
| 报告提示名称不属于任何部件 | 名称前缀不符合约定或拼写错误 | 按 1.1 节命名表重命名 |
| 负重轮不转 | 轮子与车体合并了，或名称不是 `Wheel*` | 拆开轮子、检查命名 |
| 模型太大/太小 | 单位比例不一致 | 按第 2 节比例重缩放 |
| 炮管朝向不对 | 炮管建模方向不是 +Y | 旋转模型或重新建模 |
| 炮塔悬浮/陷进车体 | 座圈高度不对 | 调整座圈高度（参考 ≈ 6） |
